O tipo Turma é onde os trabalhos nascem; turma não pode ter unidades filhas. A raiz nasce com teto US$ (aquisição) — nunca sem limite; nas filhas o teto é opcional (herda do pai).

Importar CSV

Cabeçalho name,parent_name,label,budget_usd,is_class; uma unidade por linha; o pai deve existir ou vir numa linha anterior; is_class = true marca turma.

Selecione uma unidade na árvore para gerenciar teto, membros e pacotes.

Trabalhos da turma

Teto de orçamento (US$)

O teto é uma RESERVA descontada do saldo do pai no ato; reduzir devolve ao pai. Só quem administra o nível acima define este teto (na raiz, a equipe ORATIA — é aquisição).

Pacotes de avaliação

Alocar concede N pacotes inteiros a esta unidade (só admin global). Delegar repassa pacotes de uma alocação daqui para uma unidade filha.

Configuração da instituição · equipe ORATIA

Porta da instituição (tenant)

Domínios (a pista)

Na falha do login pela porta genérica, um e-mail desse domínio sugere a porta da instituição. Não roteia automático.

Provedores da instituição (SSO)

No piloto, use mock (SSO de mentira) para testar. OIDC/SAML têm schema, runtime pendente. Segredos ficam fora do sistema.

Login aceito nesta unidade

Marque os provedores que abrem esta unidade. Nenhum marcado = aceita o login aberto (senha local / Google) — o caso avulso. Marque só o SSO para uma unidade SSO-only.

Membros e papéis

Só o papel de administrador herda para a sub-árvore. Professor e aluno valem SÓ nesta unidade: vínculo em unidade acima torna a pessoa disponível aqui (lista acima), e vincular aqui é a inscrição/atribuição. admin_global é concedido fora daqui.

Nova pessoa (cadastro + convite)

Cria a conta (sem senha), vincula no papel escolhido e gera um convite de ativação. Nada é enviado sozinho: baixe o TXT dos convites e envie você mesmo (v1 sem servidor de e-mail).
